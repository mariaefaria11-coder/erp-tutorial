# Publicar no GitHub Pages

## Estrutura correta

Envie para a raiz do repositório:

- `index.html`
- `.nojekyll`
- pasta `app`
- `README.md`

Não envie apenas o ZIP sem descompactar.

## Ativar o Pages

1. Abra o repositório no GitHub.
2. Entre em **Settings**.
3. Abra **Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione o branch `main`.
6. Selecione a pasta `/(root)`.
7. Clique em **Save**.
8. Aguarde o endereço `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## VLibras

O VLibras não funciona dentro da tela que mostra o código do arquivo no GitHub. Ele precisa ser testado no endereço publicado pelo GitHub Pages.

Confira também:

- acesso à internet;
- navegador Chrome, Firefox ou Safari;
- nenhum bloqueador impedindo scripts de `vlibras.gov.br`;
- Console do navegador sem erro de rede para `vlibras-plugin.js`;
- uso de HTTPS.

O widget é externo. Se o serviço oficial estiver indisponível ou bloqueado pela rede, o restante do ERP continua funcionando.
